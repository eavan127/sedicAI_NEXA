Human corrections: review queue
Operators correct detections on the RF Replay page, and an analyst approves or rejects each one before it can become training data; it is read-only once reviewed. An analyst's own corrections are approved directly, and recorded as such in the audit trail.

Model

Retraining from human feedback
Approved corrections become training data. A retrain fine-tunes the single model, and optionally all 5 ensemble members, on them (mixed with original training data so they do not forget), then sits a fixed exam against the version in use: a new version is only offered for activation if it does not get worse on LFM_RADAR, FHSS or JAMMING, and only an analyst can activate it. Every version is kept, including ones that failed or were rejected, so any of them, or the shipped files, can be brought back at any time.
Only an analyst starts a retrain or changes the model in use. As an operator you see which model is running and every saved version.

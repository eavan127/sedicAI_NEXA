A Dual-Branch Fusion CNN for Multi-Label RF Signal Classification

Who is transmitting, and are they hostile? NEXA reads raw radio samples, names every signal in the window (civilian comms, radar, frequency hopping, jamming) and tells the operator which tier it belongs to. It runs offline, in a browser, with a human in the loop.

02The mission

One band. Friends, the military and an adversary, all at once.

In contested spectrum, civilian traffic, military emissions and deliberate interference overlap in time and frequency. A detector that can only name one signal per window misses the most important case: a jammer sitting on top of a real transmission. NEXA answers yes or no for each class separately, so it can report both.

03How it works

From raw samples to a threat verdict in five steps.

Every window is 512 IQ samples at 3.2 MHz: 160 microseconds of radio. The same format is enforced for every source, so the model learns the signal and not where it came from.

Capture

Raw IQ from a receiver, a recording or a SigMF file, cut into windows.

2 × 512 · 3.2 MHz

Signal processing

Normalise power, then build a spectrogram (STFT) alongside the raw samples.

IQ + time-frequency

Two-branch AI

One branch reads phase in the raw IQ; the other reads chirps and hops in the spectrogram. They are fused.

dilated 1D-CNN ‖ 2D-CNN

Eight decisions

A separate calibrated yes/no per class, so overlapping signals are all reported.

8 × sigmoid · 5-model ensemble

Verdict

Detections are grouped into events on a timeline and ranked Hostile, Military, Civilian.

tier + event log

Why two branches?

Civilian modulations are defined by phase, which only raw IQ keeps. Radar chirps and frequency hops are clearest in a spectrogram. Neither view does both jobs, so the model uses both on the same window.

Where the data comes from

Real benchmark data where it exists (RadioML 2018.01A, RadChar), our own generators where it does not (FHSS, jamming, empty channel), plus overlays and mixtures of up to three signals.

Caught along the way

RadioML's shipped class list does not match its data. We found it from the signals themselves and confirmed it against an independent analysis. Using it unchecked would have mislabelled every civilian example.

What we say before you ask

  • The pass is an average over the test set. At −10 dB all three judged classes fall below 80%.
  • Radar and FHSS are tuned for recall: about 6 in 10 of their alarms are correct. A missed emitter costs more than a second look.
  • On real recorded GNSS jamming that the model never trained on, recall is 57.6% with zero false alarms. That gap is our next piece of work, and we report it rather than hide it.

Human review, four-eyes rule

Operators correct a detection or report a missed signal. A different named person must approve it before it can become training data.

Pages: RF Replay, History

Reports in any format

Filter past captures and build a report: PDF, Excel, CSV, JSON, a SigMF bundle or the raw IQ with SHA-256 hashes, each with a classification banner.

Page: History

Tamper-evident audit trail

Every analysis, export and deletion is logged. Each entry carries a hash of the one before it, so one click proves nothing was edited.

Page: History

Retraining that cannot get worse

Approved corrections fine-tune the model. A new version is offered only if it does not lose ground on radar, FHSS or jamming, and only a second person can activate it. Every version is kept for rollback.

Page: Model

Assistant that cannot invent numbers

Ask in plain language. Answers come from the stored analyses; an optional local language model only rephrases the question, so it never sees or makes up data.

Page: Assistant

Roles and offline operation

Operator, Analyst and Admin accounts. The AI runs inside the browser through ONNX, so the console works with no internet and no inference server.

NEXA gets better in service. What operators correct becomes training data, but only after a second person approves it, and a retrained model replaces the current one only if it does no worse on radar, FHSS and jamming.

06Impact

What NEXA brings to contested spectrum.

Seeing who is transmitting is only useful if it leads to a faster, better decision. NEXA is built to do that in the field, to keep working as signals change, and to stand up to scrutiny.

Operations

Clearer calls, sooner.

  • Threats surface firstJamming is ranked ahead of routine traffic, so attention goes where the risk is.
  • Overlap is not missedA jammer sitting on a live link is reported as both, the case single-answer detectors miss.
  • Works disconnectedThe full five-model ensemble runs on one laptop, with no cloud or server to depend on.
  • Decisions on recordTwo-person approval and a tamper-evident log stand behind every correction.
Deployment

Light to field, built to last.

  • Runs where a browser runsStandard ONNX models and static hosting; no GPU needed to classify.
  • Fits existing workflowsSigMF recordings in and out, with PDF, Excel, CSV and JSON reports.
  • Improves in serviceOperator corrections feed guarded retraining, with every version kept for rollback.
  • Grows with the threat pictureA new signal type is added as one more independent output.
Research

A method that can be tested.

  • Evidence, labelledEach figure is marked as a requirement, a measurement, a diagnostic or an interpretation.
  • Honest at low SNRRecall is reported per class and per noise level, not as one average.
  • Checked beyond its own dataTested on real recorded GNSS jamming it never trained on.
  • ReproducibleVersioned configurations, fixed seeds and an automated test suite.
